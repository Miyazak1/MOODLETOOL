# Moodle 外站资源嵌入与本项目替换方案

更新时间：2026-07-27

## 1. 背景

目前 Moodle 课程页中有一部分资源不是 Moodle 本地文件，而是外站嵌入或外站播放器：

- iSpring：外部 `hexstruct.ispring.com` iframe。
- H5P / quiz：外部 `welcome.hexstruct.com` iframe，或 Moodle H5P embed。
- 视频：Moodle `pluginfile.php` mp4，被 Moodle 渲染成 video.js 播放器。
- 普通文件：Moodle `pluginfile.php` docx/pdf 下载链接。

如果资源已经上传并整理到本项目，后续目标可以变成：

1. 本项目托管 iSpring、视频、H5P、PDF、DOCX 等资源。
2. 本项目为每个资源生成可粘贴到 Moodle 编辑器的 embed HTML。
3. Moodle 原本的外站调用替换为我们自己的资源地址。

## 2. 已确认的 Moodle 嵌入形式

### 2.1 iSpring

Moodle Book 的 Lesson section 中，iSpring 通常是 iframe：

```html
<iframe
  src="https://hexstruct.ispring.com/s/embed_player/..."
  width="1500"
  height="750"
  frameborder="0"
  scrolling="auto"
  allowfullscreen="allowfullscreen">
</iframe>
```

本项目替换后不应继续指向 `hexstruct.ispring.com`，而应指向本项目托管的 `presentation.html` 或专门的 embed wrapper。

建议生成：

```html
<iframe
  src="https://your-domain.com/embed/ispring/COURSE/U01L01"
  width="100%"
  height="720"
  frameborder="0"
  scrolling="auto"
  allowfullscreen="allowfullscreen">
</iframe>
```

`/embed/ispring/COURSE/U01L01` 由本项目映射到真实文件，例如：

```text
/courseware/COURSE/ispring-localized/unit-01/U01L01/presentation.html
```

或 ENG3U 这类旧结构：

```text
/courseware/ENG3U/Unit 1/Lesson 1 - Introduction to Macbeth/html5-package/presentation.html
```

### 2.2 H5P / quiz

Moodle 中出现过两种 H5P 形式：

```html
<iframe src="https://welcome.hexstruct.com/wp-admin/admin-ajax.php?action=h5p_embed&id=451"></iframe>
<script src="https://welcome.hexstruct.com/wp-content/plugins/h5p/h5p-php-library/js/h5p-resizer.js"></script>
```

以及 Moodle 自己的 H5P embed：

```text
https://www.esunnybrook.com/h5p/embed.php?url=https%3A%2F%2Fwww.esunnybrook.com%2Fpluginfile.php%2F...%2Fquestion-set-2.h5p
```

本项目目前已经能把 `.h5p` 文件作为资源下载/索引，但真正“像 Moodle 一样在线运行 H5P”需要本项目接入 H5P runtime。短期更稳的策略：

- 已能本地化 `.h5p` 文件：先提供下载。
- 需要 Moodle 页面内运行 quiz：优先仍用 Moodle 自己的 H5P 活动或 Moodle H5P embed。
- 后续如要脱离 Moodle 运行 H5P，需要单独实现 H5P player。

### 2.3 视频

Moodle Book 中的 mp4 通常来自 `pluginfile.php`，页面渲染后会变成 video.js 播放器。

源资源形态：

```html
<video controls>
  <source src="https://www.esunnybrook.com/pluginfile.php/.../SBI3U-U1L1.mp4" type="video/mp4">
</video>
```

本项目替换后建议生成：

```html
<video controls preload="metadata" style="width:100%;max-width:960px;">
  <source src="https://your-domain.com/embed/video/COURSE/U01L01/resource-id.mp4" type="video/mp4">
</video>
```

如果希望 Moodle 页面更统一，也可以用 iframe 包一层本项目的视频播放页：

```html
<iframe
  src="https://your-domain.com/embed/video/COURSE/U01L01/resource-id"
  width="100%"
  height="540"
  frameborder="0"
  allowfullscreen="allowfullscreen">
</iframe>
```

iframe wrapper 更适合后续加下载按钮、标题、访问日志和错误提示。

### 2.4 PDF / DOCX

Moodle 内原本常见为普通链接：

```html
<a href="https://www.esunnybrook.com/pluginfile.php/.../file.docx" target="_blank">HERE</a>
```

本项目可以生成：

```html
<a href="https://your-domain.com/embed/file/COURSE/U01L01/resource-id" target="_blank" rel="noopener">
  Download resource
</a>
```

如果是 PDF，可以生成 iframe 预览：

```html
<iframe
  src="https://your-domain.com/embed/file/COURSE/U01L01/resource-id"
  width="100%"
  height="720"
  frameborder="0">
</iframe>
```

DOCX 在线预览则依赖本项目生成的 HTML/PDF preview，不建议直接 iframe `.docx`。

## 3. 本项目需要新增的能力

### 3.1 Moodle Embed Generator

后台需要新增一个“生成 Moodle 嵌入代码”区域：

- 选择课程。
- 选择 Unit / Lesson。
- 选择资源类型：iSpring、video、H5P、PDF、DOCX、lesson book section。
- 显示资源列表。
- 一键复制 Moodle HTML。
- 支持批量导出 CSV/HTML 清单。

### 3.2 Embed URL 层

不建议让 Moodle 直接嵌入普通门户页面 URL，因为门户页面依赖教师登录和完整应用壳。

建议新增专门的只读 embed 路由：

```text
/embed/ispring/:course/:lessonId
/embed/video/:course/:lessonId/:resourceId
/embed/file/:course/:lessonId/:resourceId
/embed/book-section/:course/:lessonId/:sectionKey
```

这些路由输出最小 HTML 或直接转发文件，适合 iframe。

### 3.3 访问控制

这里需要提前决定安全模式：

方案 A：Moodle embed 资源公开但 URL 不可猜。

- 优点：Moodle iframe 打开最稳定。
- 缺点：只要链接泄露，别人也可能访问。

方案 B：签名 embed URL。

- URL 带 token，例如：

```text
https://your-domain.com/embed/ispring/ESLEO/U01L01?token=...
```

- token 可以绑定课程、资源路径、过期时间。
- Moodle 页面中的长期课程资源建议使用长期 token，管理员可轮换。

方案 C：要求用户同时登录本项目。

- 安全更强。
- 但 Moodle iframe 里容易遇到第三方 Cookie、SameSite、跨域登录状态问题，不推荐作为默认方案。

建议使用方案 B：签名 embed URL。

## 4. 替换 Moodle 内容的工作流

一门课完成本地化后：

1. 扫描该课程 manifest。
2. 生成 Moodle embed replacement report。
3. 对每个 Lesson section 输出：
   - 原 Moodle 外站 URL。
   - 本项目本地资源路径。
   - 推荐替换 HTML。
   - 状态：ready / missing-local-resource / needs-h5p-runtime / needs-review。
4. 管理员进入 Moodle 编辑对应 Book chapter。
5. 切换 HTML/source 模式，替换 iframe/video/link。
6. 保存后在 Moodle 前台检查播放。

后续如果有 Moodle API 权限，可以进一步自动替换 Book chapter HTML；在没有 API 权限前，先生成可复制代码更稳。

## 5. 与现有脚本的关系

现有能力：

- `scripts/crawl-moodle-book-raw.mjs`：抓 Moodle Book 原始章节。
- `scripts/export-moodle-ispring-embed-queue.mjs`：导出外部 iSpring iframe 队列。
- `scripts/export-moodle-media-localization-queue.mjs`：导出 Moodle 文件、视频、H5P 本地化队列。
- `scripts/audit-ispring-external-videos.mjs`：检查 iSpring 包内部是否仍依赖外部视频 runtime。

需要新增：

- `scripts/export-moodle-embed-replacement-report.mjs`
- 后台“复制 Moodle embed 代码”UI。
- 服务端 `/embed/*` 路由和签名 token 校验。

## 6. 结论

这件事可以做，而且应该做成平台能力。

核心不是“把本项目页面链接贴回 Moodle”，而是：

- 本项目托管资源。
- 本项目生成 Moodle 可嵌入 HTML。
- Moodle 只负责显示 iframe/video/link。
- 资源播放、下载、替换、审计由本项目统一管理。

## 7. 2026-07-27 已实现的第一版

已新增：

- 服务端签名 embed token：`EMBED_TOKEN_SECRET`。
- 服务端公开嵌入域名配置：`EMBED_PUBLIC_ORIGIN`。
- iSpring 嵌入路由：`/embed/ispring/:course/:lessonId/:resourceId?token=...`
- 视频嵌入路由：`/embed/video/:course/:lessonId/:resourceId?token=...`
- 文件/PDF/H5P 下载路由：`/embed/file/:course/:lessonId/:resourceId?token=...`
- iSpring 内部资源 token 路由：`/embed/t/:token/:course/:path`
- 后台接口：`/api/admin/moodle-embeds?course=ENG3U`
- 后台页面入口：`teacher-admin` 中的“Moodle 嵌入代码”区块。
- 批量导出脚本：

```text
npm run export:moodle-embed-replacements -- --course ENG3U --base-url https://your-domain.com --secret <EMBED_TOKEN_SECRET>
```

输出文件：

```text
deployment/moodle-embed-replacement-ENG3U.json
deployment/moodle-embed-replacement-ENG3U.md
deployment/moodle-embed-replacement-ENG3U.csv
```

这些输出包含可长期访问的签名 token，不应提交到 GitHub；已加入 `.gitignore`。

本地验证结果：

```text
ENG3U replacement rows: 623
iSpring: 37
video: 189
H5P runtime gaps: 28
```

H5P 当前只生成下载链接，并标记 `needs-h5p-runtime`。如果要在本项目中像 Moodle 一样直接运行 H5P，需要后续接入 H5P player。
