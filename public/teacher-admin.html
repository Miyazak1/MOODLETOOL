Moodle 嵌入插件教程

Portal Embed Filter 是一个 Moodle 文本过滤器插件。它让 Moodle 内容里可以粘贴短代码，由 Moodle 服务端渲染成带正确 sandbox 和 allow 权限的 iframe。

下载插件 ZIP
1. 下载插件 从本门户下载 filter_portalembed.zip，解压后目录名是 portalembed。
2. 安装到 Moodle 把目录放到 Moodle 的 filter/portalembed，然后运行 upgrade 和 purge caches。
3. 启用过滤器 在 Moodle 后台 Manage filters 里启用 Portal embed shortcode。
4. 粘贴短代码 以后在 Moodle 内容中放 shortcode，不再直接保存 iframe。

这是什么

它不是一个单独命令，也不是我们门户里的普通页面，而是标准 Moodle 插件目录：

filter/portalembed/
  version.php
  filter.php
  settings.php
  lang/en/filter_portalembed.php

在 Sunnybrook Moodle 安装

这台服务器建议继续用 PHP 8.1，避免 PHP 8.2 的 curl extension warning。

cd /www/wwwroot/www.esunnybrook.com/moodle
curl -L https://www.moodletool.work/downloads/filter_portalembed.zip -o /tmp/filter_portalembed.zip
unzip -oq /tmp/filter_portalembed.zip -d filter
/www/server/php/81/bin/php admin/cli/upgrade.php --non-interactive
/www/server/php/81/bin/php admin/cli/purge_caches.php

给其他 Moodle 网站安装

把 Moodle 路径和 PHP 命令换成对方服务器自己的路径即可。

cd /path/to/moodle
curl -L https://www.moodletool.work/downloads/filter_portalembed.zip -o /tmp/filter_portalembed.zip
unzip -oq /tmp/filter_portalembed.zip -d filter
php admin/cli/upgrade.php --non-interactive
php admin/cli/purge_caches.php

Moodle 后台启用位置

Site administration -> Plugins -> Filters -> Manage filters -> Portal embed shortcode
  • 过滤器启用后，页面内容里的短代码会在显示时变成 iframe。
  • TinyMCE 不再需要保存完整 iframe，所以不会再把 sandbox 改空。
  • 插件默认只允许 https://www.moodletool.work/embed/ 开头的资源。

短代码示例

门户课程页资源卡片上的“短代码”按钮会自动复制实际可用版本。这里是格式示例：

[portal_iframe src="https://www.moodletool.work/embed/ispring/ESLEO/U01L01/87b225257bd8?token=..." width="100%" height="720"]

更新插件包

如果以后改了插件源码，先在门户项目里重新打包并部署，下载地址会保持不变。

npm run package:moodle-filter

pm2 restart ossd-course-portal --update-env
